# Movie Explorer

Movie Explorer is a React-based application designed to browse and search TV shows and movies.

- **Live URL:** [https://movie-hub-by-cmreja.netlify.app](https://movie-hub-by-cmreja.netlify.app)

### Key Features
- **Hero Landing Page:** Features a hero banner with a quick navigation button to explore movies.
- **Live Search:** Includes a real-time search bar that instantly filters titles as you type.
- **Responsive Card Grid:** Displays movie cards with poster, title, rating (⭐), and release date (📅).
- **Details Modal:** Opens an interactive popup with backdrop image, genres list, and full summary.

### Tech Stack
- **Core:** React 19, JavaScript
- **Styling:** Tailwind CSS and DaisyUI.
- **Data:** Free Movie Database API (TVMaze).

### Setup & Info
- **Local Run:** Run `npm install` to install dependencies and `npm run dev` to launch the server.
